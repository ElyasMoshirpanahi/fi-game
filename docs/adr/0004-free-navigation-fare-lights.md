# Stations are never locked; the Fare lights them

Any Station can be opened from the Path at any time. Progression is shown, not enforced: passing a Station's Fare lights its node, awards its Badge and theme colour, and adds to XP. We rejected Duolingo-style locking because the Library Station is a shelf the player will return to out of order, and because the player already knows the material's order and does not need to be forced through it (grilling decisions 1 and 6).

## Consequences

- The visual Path must still make order attractive: unlit nodes look dimmer, not disabled.
- The final Milestone is the one exception; it depends on both Checklists being complete, not on Fares.
